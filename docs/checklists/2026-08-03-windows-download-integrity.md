# Windows 자동 다운로드 무결성 체크리스트

Date: 2026-08-03

목적: Microsoft 최신 Windows 11 Arm64 ISO 자동 다운로드가 실패·손상 파일을 성공으로 오인하지 않게 한다.

## 완료

- [x] Microsoft 공식 HTTPS 도메인과 ISO 응답만 허용한다.
- [x] 다운로드 시작 전에 HTTP 2xx 상태를 확인한다.
- [x] 알려진 Content-Length가 1 GB 미만이면 불완전 응답으로 차단한다.
- [x] 알려진 다운로드 크기와 2 GB 여유 공간을 확보하며, 크기를 모르면 10 GB를 요구한다.
- [x] 선택 언어에 대응하는 SHA-256을 Microsoft 페이지의 현재 표에서 읽는다.
- [x] 유효한 64자리 SHA-256을 얻지 못하면 다운로드를 시작하지 않는다.
- [x] 완료 ISO를 4 MiB 청크로 읽어 메모리 급증 없이 SHA-256을 계산한다.
- [x] Microsoft 게시값과 불일치하면 파일을 삭제하고 VM 준비를 중단한다.
- [x] 다운로드 또는 해시 검증 중 시트를 닫으면 작업을 취소하고 대상 파일을 삭제한다.
- [x] HTTP·공간·해시·언어·URL 정책 테스트 22개가 통과한다.
- [x] 전체 Swift 회귀 테스트 380개 / 25 suites가 통과한다.
- [x] `./script/build_and_run.sh --verify`로 ad-hoc 앱 번들 생성과 서명 검증이 통과한다.
- [x] 실제 앱에서 Windows 11 25H2 한국어 Arm64 링크와 게시 해시를 자동 취득하고 다운로드 시작을 확인한다.
- [x] 실제 다운로드를 3%에서 취소한 뒤 Application Support Downloads에 부분 ISO가 남지 않음을 확인한다.

## 남은 실기 게이트

- [ ] 전체 ISO 다운로드를 완료하고 실제 다중 GB 파일의 SHA-256 일치 상태를 확인한다.
- [ ] 검증된 ISO가 기본 VM 준비로 전달되고 임베디드 Windows Setup 화면이 표시되는지 확인한다.
- [ ] 네트워크 단절, 디스크 부족, 강제 종료를 실제 대용량 다운로드 중 재현해 복구 문구와 잔여 파일을 확인한다.

전체 ISO와 Windows 설치 실기 증거가 없으므로 상위 Parallels급 첫 실행 항목은 완료로 표시하지 않는다.
